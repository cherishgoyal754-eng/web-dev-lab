Practical P13

Choosing Between Flexbox & Grid

Flexbox (1D)

Best for single-row or single-column alignment:

  • Navigation bars (brand on left, links on right)
  • Centering components vertically or horizontally
  • Form input and button pairings
  • Fluid badge and tag wrapping

CSS Grid (2D)

Best for two-dimensional rows and columns:

  • Overall page scaffolding (header, content, sidebar)
  • Responsive auto-fitting card grids without media queries
  • Editorial column spans and newspaper layouts
  • Clean grid cell positioning without margin hacks
